# Manjun's Sequence

Manjun's Sequence is a Node.js CLI that generates ready-to-use project templates in just a few minutes.

Instead of manually creating folders, editing configuration files, and setting up credentials, Manjun's Sequence guides you through a simple interactive setup and prepares the project automatically.

Current supported template:

- Instagram UI Maxer

More templates will be added in future releases.

---

# Requirements

Before installing Manjun's Sequence, make sure you have:

- Node.js **v18 or later**
- npm

Download node.js

```bash
winget install OpenJS.NodeJS.LTS
```

Check your Node.js version:

```bash
node -v
```

Example:

```text
v24.13.0
```

Check your npm version:

```bash
npm -v
```

Example:

```text
11.6.2
```

---

# Installation

Install Manjun's Sequence globally:

```bash
npm install -g manjuns-sequence
```

Verify the installation:

```bash
manjuns-sequence --version
```

Example:

```text
1.0.1
```

You can also check the published npm version:

```bash
npm view manjuns-sequence version
```

---

# Running the CLI

Launch the project generator:

```bash
manjuns-sequence
```

You will see something similar to:

```text
Welcome to Manjun's Sequence!

🚀 MANJUN'S SEQUENCE GENERATOR

[1] Instagram UI Maxer
[2] Exit
```

Choose a project to begin.

---

# Instagram UI Maxer Setup

After selecting **Instagram UI Maxer**, the CLI will ask for your Supabase credentials.

Example:

```text
Enter Supabase URL:
```

Paste your project URL.

Example:

```text
https://your-project.supabase.co
```

Next:

```text
Enter Supabase Anon Key:
```

Paste your anon public key.

The CLI will then:

- Copy the complete project template
- Configure your credentials automatically
- Generate the finished project
- Save everything to your Desktop

Example output:

```text
Project created successfully!

Location:

C:\Users\<YourName>\Desktop\Instagram-UI-Maxer
```

# Creating a Supabase Project

## 1. Create an Account

Visit:

https://supabase.com

Sign in or create a free account.

---

## 2. Create a Project

Inside the dashboard:

- Click **New Project**
- Choose your organization
- Enter a project name
- Create a database password
- Select a region
- Click **Create Project**

Wait until provisioning is complete.

---

# Create the Database Table

Open:

```
Supabase Dashboard

↓

SQL Editor

↓

New Query
```

Run:

```sql
create table if not exists public.tokens (
    id bigint generated by default as identity primary key,
    token text not null,
    source text,
    created_at timestamptz default now()
);
```

Click **Run**.

# Generated Project

After setup, your Desktop will contain:

```text

├── manifest.json
├── popup.html
├── popup.js
├── background.js
├── credentials.js
├── icons/
└── ...
```

The CLI automatically inserts your Supabase URL and anon key into:

```text

```

No manual editing is required.

# Troubleshooting

## Command not found

Reinstall globally:

```bash
npm uninstall -g manjuns-sequence

npm install -g manjuns-sequence
```

Check the executable:

```bash
where manjuns-sequence
```

Windows should return something similar to:

```text
C:\Users\<YourName>\AppData\Roaming\npm\manjuns-sequence.cmd
```

---

## Template Not Found

If you receive:

```text
ENOENT: no such file or directory
```

Make sure the published package contains the `templates` directory.

Verify your `package.json` includes:

```json
"files": [
  "bin",
  "src",
  "templates",
  "README.md"
]
```

Republish the package after making changes.

---

## Supabase Configuration Issues

Verify that:

- Your project is active
- The Project URL is correct
- The Anon Key is correct
- The `tokens` table exists
- Your internet connection is working
