# 🚀 Manjun's Sequence

Manjun's Sequence is a developer-focused CLI tool that helps users quickly initialize and configure projects through an interactive terminal workflow.

It provides:

- Beautiful CLI interface
- Automated setup
- Configuration management
- Backend connection support
- Developer-friendly workflow

> This project is designed for developers who want a faster way to create and manage project environments.

---

# 📌 Requirements

Before installing Manjun's Sequence, make sure you have:

- Node.js installed
- npm installed
- Git installed (recommended)
- A Supabase account (if using database features)

Check versions:

```bash
node -v
```

```bash
npm -v
```

# 📦 Installation

Install Manjun's Sequence globally:


Check installation:


If installed correctly, you should see the current version.

# 🗄️ Supabase Setup

Manjun's Sequence supports Supabase for storing project information and configuration data.

## Step 1 — Create Supabase Account

Go to:

https://supabase.com

Create an account using:

- GitHub
- Email
- Google

---

## Step 2 — Create a New Project

After logging in:

1. Click **New Project**
2. Select your organization
3. Enter project name:

Example:

```
manjun-sequence
```

4. Create a secure database password
5. Select a region
6. Click **Create Project**

Wait until the project finishes creating.

---

# Step 3 — Create Database Table

Open:

```
Supabase Dashboard
        ↓
SQL Editor
        ↓
New Query
```

Paste:

```sql
create table if not exists projects (
    id bigint generated by default as identity primary key,
    name text not null,
    description text,
    owner text,
    created_at timestamptz default now()
);
```

Click:

```
Run
```

Your database is now ready.

---

# Step 4 — Get Supabase API Keys

Go to:

```
Supabase Dashboard

Settings

API
```

Copy:

```
Project URL
```

and

```
anon public key
```

Example:

```
URL:
https://xxxxxxxx.supabase.co


KEY:
eyJhbGciOiJIUzI1...
```

Keep these values private.

---

# Step 5 — Configure Environment

Create a file:

```
.env
```

Add:

```env
SUPABASE_URL=https://your-project.supabase.co

SUPABASE_KEY=your-anon-key
```

Example:

```env
SUPABASE_URL=https://abcdxyz.supabase.co

SUPABASE_KEY=eyJhbGciOiJIUzI1...
```

# ❌ Troubleshooting

## Command not found

If you see:

```
manjun is not recognized
```

Restart your terminal.

Or reinstall:

```bash
npm uninstall -g manjun-sequence
```

then:

```bash
npm install -g manjun-sequence
```

---

## Supabase Connection Error

Check:

- Supabase URL is correct
- API key is correct
- Internet connection works
- Database table exists

---

## Permission Error

Run terminal as administrator.

---

# 🔒 Security Recommendations

- Never upload `.env` files to GitHub
- Never share Supabase service keys
- Use environment variables
- Rotate exposed keys immediately

Add:

```
.env
```

to:

```
.gitignore
```
