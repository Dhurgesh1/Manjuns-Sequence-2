# Manjun's Sequence

Manjun's Sequence is a CLI tool that helps automate project setup and configuration.

---

## Requirements

Install the following before using Manjun's Sequence:

- Node.js (v18 or above)
- npm

Check installation:

```bash
node -v
```

```bash
npm -v
```

---

# Installation

Install Manjun's Sequence globally:

```bash
npm install -g manjun-sequence
```

Check if it is installed:

```bash
manjun --version
```

---

# Running Manjun's Sequence

Start the CLI:

```bash
manjun
```

Follow the instructions shown in the terminal.

---

# Supabase Setup

Manjun's Sequence uses Supabase for database storage.

## 1. Create Supabase Account

Go to:

https://supabase.com

Create an account and login.

---

## 2. Create a Project

1. Click **New Project**
2. Enter project name
3. Create a database password
4. Select a region
5. Click **Create Project**

Wait until the project is ready.

---

## 3. Create Database Table

Open:

```
Supabase Dashboard
→ SQL Editor
→ New Query
```

Run:

```sql
create table projects (
    id bigint generated by default as identity primary key,
    name text not null,
    description text,
    created_at timestamptz default now()
);
```

---

# Supabase Credentials

Open:

```
Supabase Dashboard
→ Settings
→ API
```

Copy:

- Project URL
- Anon Public Key

---

# Configuration

Create a file named:

```
.env
```

Add:

```env
SUPABASE_URL=your_project_url

SUPABASE_KEY=your_anon_key
```

Example:

```env
SUPABASE_URL=https://example.supabase.co

SUPABASE_KEY=your_key_here
```

# Troubleshooting

## Command not found

Reinstall:

```bash
npm uninstall -g manjun-sequence
```

```bash
npm install -g manjun-sequence
```

---

## Supabase Connection Error

Check:

- `.env` file exists
- Supabase URL is correct
- API key is correct
- Database table exists

---

## Security

- Do not share your Supabase keys
- Do not upload `.env` to GitHub
- Keep credentials private
